Diagram Suggested · Mobile clinic site selection
From zip code risk score to clinic date — the full approval pathway
Getting a mobile clinic placed requires three independent approvals. The hospital network and city health department tracks run in parallel — both must clear before the host site can be approached. Based on Chicago's Protect Chicago+ rollout, this process typically takes 4–6 weeks from shortlist to confirmed date.

Woodson et al. (2024) · J Public Health Mgmt Practice
Documents Chicago's Protect Chicago+ program — the real-world model for this pathway. Describes how CDPH identified vulnerable zip codes, coordinated with hospital systems, and used community-level outreach to drive clinic placement decisions.
City of Chicago CDPH · covid19.chicago.gov
Primary source for the zip code prioritization framework and the parallel approval structure between CDPH and hospital network partners. The Protect Chicago+ design explicitly required both tracks to clear before sites were confirmed.
Rennert L et al. (2024) · Public Health Practice
Peer-reviewed case study of mobile health clinic deployment across South Carolina. Establishes that site selection based on census tract risk scoring — the same logic used in Step 1 here — was the strongest predictor of uptake impact in underserved communities.
