Security Principles
Transport
Encrypted in Transit
All channels including webhook receipt, SSE delivery, and AI API calls run exclusively over TLS 1.3. No unencrypted paths exist in the pipeline.
TLS 1.3
Integrity
Webhook Verification
Every Recall.ai event carries an HMAC-SHA256 signature. The server rejects any event that fails signature validation before it enters the pipeline.
HMAC-SHA256
Access Control
Credential Isolation
All third-party API keys live exclusively in server-side environment variables. Nothing sensitive is bundled into the client or exposed to the browser.
Server-Side Only
Data Handling
Zero Persistence
Transcript data is held in-memory for the duration of the session only. No database writes occur. All session data is cleared automatically on disconnect.
Ephemeral Memory
